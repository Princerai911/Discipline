01 Executive Summary & Core Philosophy

Discipline is not a passive todo list or casual habit tracker. It is an aggressive execution protocol modeled after high-stakes personal discipline regimens.

⚡ Single-Task Lock Engine

Once an objective timer begins, the user is locked into that task. All other daily routines display 🔒 LOCKED to eliminate context-switching and mental dithering.

🚫 Honest Penalization

Tasks cannot be casually checked off or toggled back and forth. You either see the timer through to completion or tap Abort / Quit, permanently logging a failure and turning progress rings red.

⏱️ Real-Clock Resilience

Timers calculate duration against absolute wall-clock timestamps (Date.now()). Locking mobile screens or backgrounding browser tabs will never pause, drift, or corrupt countdowns.

📶 Offline-First Queue

Active focus state and task completions are stored in localStorage. When offline, actions queue up and automatically sync with Supabase when internet connectivity is re-established.

04 Data Models & Database Schemas

The Supabase (PostgreSQL) schema decouples overarching long-term goals from scheduled daily routine execution instances.

1. public.goals

Master goals/categories grouping routines.

  • id: uuid (PK, default gen_random_uuid())
  • title: text (NOT NULL)
  • description: text (optional)
  • user_id: uuid (FK auth.users.id)
  • created_at: timestamptz

2. public.tasks

Daily recurring routines with time-blocks.

  • id: uuid (PK, default gen_random_uuid())
  • goal_id: uuid (FK goals.id ON DELETE CASCADE)
  • title: text (NOT NULL)
  • scheduled_time: time (Start time, e.g. 07:00:00)
  • end_time: time (Target finish time, e.g. 08:00:00)
  • created_at: timestamptz

3. public.task_completions

Daily execution audit trail with unique daily constraint.

  • id: uuid (PK, default gen_random_uuid())
  • task_id: uuid (FK tasks.id ON DELETE CASCADE)
  • date: date (DEFAULT current_date)
  • status: text ('completed' | 'quit')
  • completed_at: timestamptz
  • Constraint: UNIQUE(task_id, date)

4. public.notes

Reflective journaling and mind-clearing entries.

  • id: uuid (PK, default gen_random_uuid())
  • content: text (NOT NULL)
  • user_id: uuid (FK auth.users.id)
  • created_at: timestamptz

05 Page-by-Page Feature Breakdown

A. Execution Phase / Today Dashboard (/)

  • Protocol List: Daily routines ordered by scheduled_time. Each routine shows start time, title, parent goal badge, and execution status (PENDING, SUCCESS, or FAILED).
  • Interactive Focus Session: Initiating focus computes duration in seconds ((endTime - startTime) with a 25-minute fallback) and renders a prominent countdown clock with dynamic glowing borders.
  • Strict Task Locking: Any non-focused task switches its button to 🔒 LOCKED, prompting the user with a warning toast if tapped.
  • Gamification HUD:
    • Streak Display: Consecutive active days calculation with a subtle flame emoji for streaks > 2.
    • Dynamic Circular Progress Ring: SVG SVG-dashoffset ring that turns Emerald Green (≥80%), Purple (≥50%), or Crimson Red if any failure/quit was recorded.

B. Master Plan / Goals Management (/goals)

  • Create high-level objectives (e.g. "Physical Mastery", "Deep Engineering").
  • Add recurring daily habits under each goal specifying title, start time, and end time.
  • Includes client-side validation preventing identical start and end timestamps and empty titles.
  • Inline habit editing and cascade deletion with confirmation dialogues.

C. Discipline Analytics & Calendar Heatmap (/stats)

  • Calculates both Current Active Streak and All-Time Longest Streak.
  • Intelligent Calendar Heatmap:
    • Days prior to first goal creation remain neutral/muted.
    • Past days with 0 completions highlight in glowing Red to expose broken discipline.
    • Current ongoing day stays neutral with violet accent so users aren't unfairly penalized during the daytime.
    • Active completion days scale in vibrant green/purple intensity based on volume.

D. Daily Journal / Reflections (/notes)

  • Uncluttered reflection textarea for night reviews: "What went well today, what will I improve tomorrow."
  • Reverse chronological feed displaying formatted weekday, date, and 12-hour timestamp tags.

06 Key Technical Mechanisms & Resiliency

1. Wall-Clock Absolute Timer (Zero Background Drift)

Mobile operating systems aggressively throttle or freeze JavaScript setInterval timers when screens turn off or tabs are backgrounded. Discipline avoids this by calculating: 

targetEndTime = Date.now() + (durationSeconds * 1000);
// On every tick:
remaining = Math.round((targetEndTime - Date.now()) / 1000);

Upon re-opening the phone, the exact wall-clock time remaining is calculated instantly. If the duration elapsed while locked, it immediately triggers the completion audio and state.

2. Offline Storage & Background Sync Queue

Focus sessions and completions persist through device reboots and spotty connections:

  • active_focus_session: Stores current task ID and target timestamp in localStorage.
  • offline_sync_queue: If a task is completed or quit while offline, an item { task_id, date, status } is stored locally.
  • Automatic sync triggers on window.online and on document visibilitychange.

3. Timezone-Safe Date Math & Midnight Reset

Standard toISOString() introduces UTC date shifts that cause daily tasks to reset at the wrong hour. Discipline normalizes all dates with: 

const offset = localDate.getTimezoneOffset();
const todayStr = new Date(localDate.getTime() - (offset * 60 * 1000)).toISOString().split('T')[0];

A midnight setTimeout plus a visibilitychange date diff check ensures sleeping mobile tabs auto-refresh to day one as soon as the user unlocks their phone the next morning.
